# Регрессионный корпус правил ToolRise ChatMod.
# Запуск:  ./gradlew -q rules --args="verify"
#
# Формат:
#   FLAG <id>|текст   — обязано сработать именно это правило
#   FLAG|текст        — обязано сработать хоть какое-то правило
#   CLEAN|текст       — не должно сработать ничего
#
# Каждый новый пойманный обход добавляется сюда строкой FLAG,
# а каждое погашенное ложное срабатывание — строкой CLEAN.
# Без этого правки правил невозможно проверить.
